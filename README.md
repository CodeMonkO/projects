# Claude Large System Architect Package

This package is for using Claude as a high-grade architecture partner for large complex systems, not only AI-SDLC.

Use it for:
- distributed systems
- enterprise platforms
- agentic AI products
- cloud-native systems
- workflow platforms
- SaaS systems
- high-scale APIs
- data platforms
- platform engineering
- architecture reviews
- executive architecture communication

## Main File

Use `CLAUDE.md` as the main instruction file.

## Suggested Usage

Place `CLAUDE.md` in your project root. Keep the other files in a `/docs/architecture-ai/` folder or similar.

When starting a design task, tell Claude:
> Use CLAUDE.md and the architecture package as your operating mode. Act as my senior architecture partner.
