# Prompt Library for Large System Architecture

## 1. Deep System Design Prompt

Act as a Senior System Architect.

Design a large-scale system for the following problem.

Return:
1. Problem summary
2. Requirements
3. Assumptions
4. High-level architecture
5. Component responsibilities
6. Data model
7. APIs/contracts
8. Data flow
9. Failure modes
10. Security
11. Observability
12. Cost and scaling
13. Alternatives
14. MVP
15. North Star
16. Open decisions

## 2. Agentic AI Architecture Prompt

Act as a Senior Agentic AI Architect.

Design an agentic AI system for the following use case.

Use:
- agent registry
- tool registry
- workflow builder
- workflow runner
- policy engine
- context engine
- memory/state
- harness validation
- human approval
- audit/cost tracking

Return:
1. Architecture
2. Agent roles
3. Workflow lifecycle
4. Tool safety model
5. Context model
6. Validation model
7. Failure modes
8. Security risks
9. MVP
10. Mermaid diagram

## 3. Architecture Review Prompt

Review the following architecture.

Return:
1. What is strong
2. What is unclear
3. Hidden assumptions
4. Major risks
5. Missing components
6. Failure modes
7. Security concerns
8. Operational concerns
9. Simpler alternative
10. Recommended next version

## 4. Plain Language Rewrite Prompt

Rewrite the following technical architecture in plain language.

Rules:
- simple words
- no corporate jargon
- explain why it matters
- explain tradeoffs
- keep it natural
- preserve technical correctness

## 5. Risk Discovery Prompt

Act as a Chief Architect.

Find early problems in this system design.

Look for:
- unclear ownership
- hidden coupling
- scaling risk
- security risk
- data risk
- workflow risk
- operational risk
- cost risk
- adoption risk
- migration risk
- long-term maintenance risk
