# Cloud and Platform Architecture Guide

## Platform Capabilities

A mature platform should provide:
- service templates
- deployment pipelines
- secrets management
- observability
- logging/tracing
- policy enforcement
- cost dashboards
- service catalog
- ownership registry
- incident runbooks
- golden paths

## Cloud-Native Checklist

- containerized workload
- health checks
- readiness/liveness probes
- autoscaling
- resource limits
- graceful shutdown
- structured logs
- metrics
- traces
- secrets externalized
- config externalized
- zero-downtime deploy
- rollback

## Deployment Strategies

- rolling deployment
- blue/green
- canary
- feature flags
- shadow traffic
- progressive delivery

## Platform Design Principle

Do not make every team solve the same infra problem.

Create golden paths, not forced paths.
